## Usage

```tsx
import {
  Pokedex,
  PokedexSearch,
  PokedexClear,
  PokedexItems,
  PokedexEmpty,
  PokedexLoadMore,
  PokedexCount,
  usePokedex,
} from "@/components/compodex/ui/pokedex"
import { EmptyHeader, EmptyTitle } from "@/components/ui/empty"
```

```tsx
<Pokedex items={pokemon} pageSize={24}>
  <PokedexSearch />
  <PokedexItems renderItem={(p) => <MiCard pokemon={p} />} />
  <PokedexEmpty>
    <EmptyHeader>
      <EmptyTitle>Sin resultados</EmptyTitle>
    </EmptyHeader>
  </PokedexEmpty>
  <PokedexLoadMore />
</Pokedex>
```

Por defecto el root filtra los `items` comparando la query normalizada contra `item.name`, `PokedexItems` renderiza un grid responsive y `PokedexLoadMore` gestiona sus propios labels. Los datos y el fetching son tuyos.

### Estado controlado

Cada pieza de estado acepta el patrón `value` / `defaultValue` / `onChange`, así puedes sincronizar la búsqueda con la URL, un formulario o estado externo.

```tsx
const [query, setQuery] = useState(searchParams.get("q") ?? "")

<Pokedex items={pokemon} query={query} onQueryChange={setQuery}>
  {/* ... */}
</Pokedex>
```

### Filtrado en el servidor

Si tus items ya llegan filtrados (búsqueda server-side, índice externo), desactiva el filtrado interno con `shouldFilter`.

```tsx
const { data } = useQuery({
  queryKey: ["pokemon", query],
  queryFn: () => searchPokemon(query),
})

<Pokedex
  items={data ?? []}
  shouldFilter={false}
  query={query}
  onQueryChange={setQuery}
>
  {/* ... */}
</Pokedex>
```

### Filtros con conocimiento de datos

El shape de filtros (`PokedexFilterState`) cubre generaciones, tipo primario/secundario, legendarios y míticos. Solo tu app sabe a qué generación pertenece cada Pokémon, así que inyecta un `filterFn` propio — o pre-filtra y usa `shouldFilter={false}`.

```tsx
<Pokedex
  items={pokemon}
  filterFn={(item, query, filters) =>
    item.name.includes(query) &&
    (filters.generations.length === 0 ||
      filters.generations.includes(miIndice.get(item.name)?.generation ?? ""))
  }
>
  {/* ... */}
</Pokedex>
```

### Infinite scroll

`usePokedex()` expone todo el estado del contexto. Conecta `loadMore` a un IntersectionObserver en lugar del botón.

```tsx
function InfiniteSentinel() {
  const { hasMore, loadMore } = usePokedex()
  const ref = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!ref.current || !hasMore) return
    const observer = new IntersectionObserver(
      ([entry]) => entry.isIntersecting && loadMore(),
    )
    observer.observe(ref.current)
    return () => observer.disconnect()
  }, [hasMore, loadMore])

  return <div ref={ref} />
}
```

## Accessibility

`PokedexSearch` es un `<input>` de texto estándar — añade tu propio `aria-label` o asócialo a un `<label>`. El botón de limpiar integrado y `PokedexClear` exponen labels accesibles y se deshabilitan cuando no aplican.

### Keyboard interactions

| Key | Description |
| --- | --- |
| `Escape` | Limpia la búsqueda si hay texto. Con la query vacía, el evento sigue propagándose (p. ej. para cerrar un diálogo contenedor). |

## API Reference

### Pokedex

Root del conjunto. Posee el estado de búsqueda, filtros y paginación, y lo expone por contexto a los subcomponentes. `query` y `filters` siguen el patrón controlado/no controlado. Además acepta todas las props nativas de `<div>`.

<PropsTable of="pokedex" component="Pokedex" />

### PokedexSearch

Input de búsqueda ligado a la query del contexto, con icono de búsqueda y botón de limpiar integrado (visible solo cuando hay texto). `className` se aplica al contenedor; el resto de props van al `<input>`, del que además acepta todas las props nativas.

<PropsTable of="pokedex" component="PokedexSearch" />

### PokedexClear

Botón que resetea la búsqueda, los filtros o ambos. Se deshabilita solo cuando no hay nada que limpiar. Además acepta todas las props nativas de `<button>`.

<PropsTable of="pokedex" component="PokedexClear" />

### PokedexItems

Renderiza los items visibles (ventana de paginación incluida) con la key resuelta por `getItemKey`. Grid responsive por defecto; cualquier layout (lista, tabla, masonry) sobreescribiendo `className`. Además acepta todas las props nativas de `<div>`.

<PropsTable of="pokedex" component="PokedexItems" />

### PokedexEmpty

Estado vacío. Solo se renderiza cuando no hay coincidencias y `loading` es `false`. Compón su contenido con `EmptyHeader`, `EmptyTitle`, `EmptyDescription` y `EmptyContent`. Expone `data-reason="no-match"` cuando hay query o filtros activos y `data-reason="no-items"` cuando simplemente no llegaron datos. Además acepta todas las props nativas de `<div>`.

### PokedexLoadMore

Botón de paginación. Devuelve `null` si no hay `pageSize` o no hay coincidencias; al agotar resultados se deshabilita y expone `data-state="exhausted"`. Además acepta todas las props nativas de `<button>`.

### PokedexCount

Conteo de resultados. Además acepta todas las props nativas de `<span>`.

### usePokedex

Hook de acceso al contexto — debe usarse dentro de `<Pokedex>`. Tipable con `usePokedex<MiTipo>()`.

| Propiedad | Type | Description |
| --- | --- | --- |
| `items` | `T[]` | Todos los items, tal como llegaron. |
| `matchedItems` | `T[]` | Items tras aplicar `filterFn` (o `items` si `shouldFilter` es `false`). |
| `visibleItems` | `T[]` | Coincidencias recortadas por la ventana de paginación. |
| `query` / `queryNormalized` | `string` | Query cruda y normalizada (trim + lowercase). |
| `setQuery` | `(query: string) => void` | Actualiza la query. |
| `filters` | `PokedexFilterState` | Estado de filtros actual. |
| `setFilters` | `(filters \| updater) => void` | Reemplaza o actualiza los filtros. |
| `toggleGeneration` / `togglePrimaryType` / `toggleSecondaryType` | `(name: string) => void` | Alterna un valor en la lista correspondiente. |
| `setGenerations` | `(names: string[]) => void` | Reemplaza la selección de generaciones (p. ej. radio). |
| `setLegendaryOnly` / `setMythicalOnly` | `(value: boolean) => void` | Activa/desactiva los flags. |
| `clearFilters` | `() => void` | Resetea a `EMPTY_POKEDEX_FILTERS`. |
| `hasActiveFilters` | `boolean` | `true` si algún filtro está activo. |
| `pageSize` | `number \| null` | `null` cuando la paginación está desactivada. |
| `visibleCount` | `number` | Tamaño actual de la ventana. |
| `hasMore` | `boolean` | Quedan items por mostrar. |
| `loadMore` | `() => void` | Amplía la ventana en `pageSize`. |
| `loading` | `boolean` | El `loading` del root. |

### PokedexFilterState

```tsx
type PokedexFilterState = {
  generations: string[]      // nombres de la API, p. ej. "generation-i"
  primaryTypes: string[]     // tipos permitidos en slot 1 — unión (OR)
  secondaryTypes: string[]   // tipos permitidos en slot 2 — unión (OR)
  legendaryOnly: boolean
  mythicalOnly: boolean
}
```

`EMPTY_POKEDEX_FILTERS` se exporta como valor inicial/reset.

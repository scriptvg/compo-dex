## Usage

```tsx

```

```tsx

```

## Examples

### Type
Usa la prop `type` para mostrar el tipo elemental del Pokémon, lo que define el color de fondo y texto de la insignia.

<ComponentPreview name="pokemon-badge-variants" />

### Combined
Usa la prop `variant` para cambiar el estilo visual de la insignia. Ten en cuenta que algunas variantes pueden no ser ideales para ciertos tipos debido a sus colores.

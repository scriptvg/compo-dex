## Usage

```tsx
import {
  PokemonCard,
  PokemonCardHeader,
  PokemonCardTitle,
} from "@/components/compodex/ui/pokemon-card"
```

```tsx
<PokemonCard type="fire">
  <PokemonCardHeader>
    <PokemonCardTitle>Charmander</PokemonCardTitle>
  </PokemonCardHeader>
</PokemonCard>
```

The card surface reads its color from the type-colors theme token (`pokemon-type-colors`). Pass a `secondary` type to get a dual-type gradient surface blending both colors. The `mega` prop replaces the type surface with an animated rainbow for Mega-evolved Pokémon.

## Examples

### Dual type

Pass the `secondary` prop to render a gradient surface that blends the primary and secondary type colors.

<ComponentPreview name="pokemon-card-dual" />

### With sprite

`PokemonCardMedia` is a positioning slot: place a [Pokemon Sprite](/docs/components/pokemon-sprite) inside it to render the artwork. When the image fails to load (or there is no artwork yet), `PokemonSpriteFallback` keeps the composition intact instead of leaving an empty hole.

<ComponentPreview name="pokemon-card-sprite" />

### Type badges and overlays

Anchor chips over the artwork with `PokemonCardOverlay`: the dex number top-left, a [Pokemon Badge](/docs/components/pokemon-badge) group top-right, and status flags in the bottom corners. Each overlay pins flush to its corner via the `position` prop.

<ComponentPreview name="pokemon-card-badges" />

### Mega

The `mega` prop replaces the type surface with the animated rainbow used by Mega-evolved forms. Everything else composes the same way.

<ComponentPreview name="pokemon-card-mega" />

### Size

Use `size="sm"` for denser layouts like grids: paddings and gaps tighten across every slot.

<ComponentPreview name="pokemon-card-sm" />

## Usage

```tsx
import {
  PokemonSprite,
  PokemonSpriteImage,
  PokemonSpriteFallback,
  PokemonSpriteGroup,
  PokemonSpriteGroupCount,
} from "@/components/compodex/ui/pokemon-sprite"
```

```tsx
<PokemonSprite>
  <PokemonSpriteImage src="/sprites/pikachu.png" alt="Pikachu" />
  <PokemonSpriteFallback>PK</PokemonSpriteFallback>
</PokemonSprite>
```

## API Reference

### PokemonSprite

Contenedor raíz del sprite. Acepta todas las props de `Avatar.Root`.

<PropsTable of="pokemon-sprite" component="PokemonSprite" />

### Subcomponentes

| Componente | Base | Description |
| --- | --- | --- |
| `PokemonSpriteImage` | `Avatar.Image` | Renderiza la imagen del Pokémon. Acepta las props de `Avatar.Image`. |
| `PokemonSpriteFallback` | `Avatar.Fallback` | Contenido mostrado mientras la imagen carga o si falla. Acepta las props de `Avatar.Fallback`. |
| `PokemonSpriteBadge` | `<span>` | Insignia posicionada sobre el sprite. Acepta las props de un `<span>`. |
| `PokemonSpriteGroup` | `<div>` | Agrupa varios sprites con solapamiento. Acepta las props de un `<div>`. |
| `PokemonSpriteGroupCount` | `<div>` | Muestra el conteo restante dentro de un grupo. Acepta las props de un `<div>`. |

## Usage

```tsx
import {
  PokemonStat,
  PokemonStatLabel,
  PokemonStatValue,
  PokemonStatBar,
  PokemonStatList,
} from "@/components/compodex/ui/pokemon-stat"
```

```tsx
<PokemonStat stat="hp" value={78}>
  <PokemonStatLabel />
  <PokemonStatBar />
</PokemonStat>
```

Cada fila es un `Field` de shadcn: un `FieldLabel` (nombre + valor) sobre un `Progress`, enlazados con `htmlFor` / `id` igual que el ejemplo de progress con label de shadcn. El root es **layout + contexto**: tú compones las partes. Con un `stat` conocido (`hp`, `attack`, `defense`, `special-attack`, `special-defense`, `speed`) se autocompletan etiqueta y color; la barra se escala contra `max` (por defecto `255`).

Por defecto `PokemonStatLabel` muestra `nombre … valor` (el valor empujado a la derecha con `ml-auto`). Pásale children para recomponer la fila.

## Examples

### Lista con render prop

`PokemonStatList` recibe los datos por `stats` (un array de entries o un record `{ stat: value }`) y un **render prop** como children que decide cómo se pinta cada fila. La lista solo itera, normaliza el orden y pone la `key`.

```tsx
const stats = {
  hp: 78,
  attack: 84,
  defense: 78,
  "special-attack": 109,
  "special-defense": 85,
  speed: 100,
}

<PokemonStatList stats={stats}>
  {(entry) => (
    <PokemonStat {...entry}>
      <PokemonStatLabel />
      <PokemonStatBar />
    </PokemonStat>
  )}
</PokemonStatList>
```

<Callout type="tip">
El render prop pasa una función como children, así que el consumidor debe ser un Client Component (`"use client"`).
</Callout>

### Composición manual

Sin `stats`, `PokemonStatList` es solo un wrapper de espaciado: compón las filas a mano.

```tsx
<PokemonStatList>
  <PokemonStat stat="hp" value={78}>
    <PokemonStatLabel />
    <PokemonStatBar />
  </PokemonStat>
  <PokemonStat stat="speed" value={100}>
    <PokemonStatLabel />
    <PokemonStatBar />
  </PokemonStat>
</PokemonStatList>
```

### Label a medida

Como las partes leen el contexto, puedes recomponer la fila del label. `PokemonStatValue` lleva el valor; colócalo donde quieras.

```tsx
<PokemonStat stat="attack" value={84}>
  <PokemonStatLabel>
    <span>Ataque</span>
    <PokemonStatValue className="ml-auto text-primary" />
  </PokemonStatLabel>
  <PokemonStatBar className="h-1" />
</PokemonStat>
```

### Stat personalizado

Para stats fuera del set conocido, pasa `label`, `color` y `max` tú mismo.

```tsx
<PokemonStat label="Total" value={530} max={780} color="var(--primary)">
  <PokemonStatLabel />
  <PokemonStatBar />
</PokemonStat>
```

## Accessibility

`PokemonStatBar` se apoya en el `Progress` de shadcn (Radix), que ya expone `role="progressbar"` con `aria-valuenow` / `aria-valuemin` / `aria-valuemax`. Encima:

- El valor real (`value / max`, no el porcentaje) se anuncia vía `aria-valuetext`.
- `PokemonStatLabel` es un `FieldLabel` con `htmlFor` apuntando al `id` de la barra (generado con `useId`), igual que el patrón de progress con label de shadcn.

## API Reference

### PokemonStat

Root de una fila de stat — un `Field` de shadcn. Posee `value` + `max`, deriva el porcentaje y el color, y los comparte por contexto. Además acepta todas las props de `Field`.

<PropsTable of="pokemon-stat" component="PokemonStat" />

### PokemonStatLabel

Fila del label sobre la barra, renderizada con el `FieldLabel` de shadcn y enlazada a la barra por `htmlFor`. Por defecto muestra `nombre … valor`; pasa children para recomponer. Acepta todas las props de `FieldLabel`.

### PokemonStatValue

Valor numérico del stat. Por defecto muestra `value` del contexto; pasa children para sobreescribirlo. Acepta todas las props nativas de `<span>`.

### PokemonStatBar

La barra — el `Progress` de shadcn recoloreado por stat vía la variable `--stat-color`.

<PropsTable of="pokemon-stat" component="PokemonStatBar" />

### PokemonStatList

Wrapper de espaciado. Con `stats` + un `children` render prop renderiza desde datos; sin ellos, compón `<PokemonStat>` a mano. Además acepta todas las props nativas de `<div>`.

<PropsTable of="pokemon-stat" component="PokemonStatList" />

### usePokemonStat

Hook de acceso al contexto — debe usarse dentro de `<PokemonStat>`.

| Propiedad | Type | Description |
| --- | --- | --- |
| `name` | `PokemonStatName \| undefined` | El `stat` del root, si se pasó. |
| `value` / `max` | `number` | Valor base y escala. |
| `percent` | `number` | `value / max` recortado a 0–100 (lo que consume `PokemonStatBar`). |
| `label` | `string` | Etiqueta resuelta. |
| `color` | `string` | Color resuelto del stat. |
| `id` | `string` | Enlaza el `FieldLabel` (`htmlFor`) con la barra (`id`). |

### Constantes

| Export | Description |
| --- | --- |
| `POKEMON_STAT_ORDER` | Orden canónico de los stats (como los devuelve PokéAPI). |
| `POKEMON_STAT_LABEL` | Mapa stat → etiqueta (`hp` → `HP`, `special-attack` → `Sp. Atk`…). |
| `POKEMON_STAT_COLOR` | Mapa stat → color (hex inline, sin tokens externos). |
| `POKEMON_STAT_MAX` | Tope práctico de un stat base (`255`). |

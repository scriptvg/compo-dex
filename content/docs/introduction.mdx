**compodex** es una librería de componentes con temática Pokémon construida sobre
Next.js, React y Tailwind CSS. Combina un sitio de documentación con una Pokédex
funcional que consume la PokéAPI.

## Qué incluye

- **Components** — primitivos de UI como `PokemonBadge`, `PokemonCard` y `PokemonSprite`.
- **Blocks** — bloques compuestos listos para usar (tarjetas, búsqueda, filtros de la Pokédex).
- **Docs** — esta documentación, con preview en vivo y código fuente de cada ejemplo.

## Filosofía

Cada componente sigue el mismo patrón: estilos con `class-variance-authority`,
composición por slots y variantes por tipo de Pokémon. El objetivo es que copiar
un ejemplo y adaptarlo sea inmediato.
